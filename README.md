# عزبة (Ezbah)

تطبيق أندرويد متكامل باللغة العربية (واجهة RTL حديثة) لإدارة مصاريف أي **عزبة** أو سكن مشترك بشكل احترافي ومرن: تقسيم الإيجار، الكهرباء، والماء (عند فصله عن الإيجار)، متابعة الدفعات المتقلبة والأرصدة المدفوعة مقدماً، الترحيل التلقائي، تحليل استهلاك الكهرباء، وتذكيرات واتساب الطبيعية مع إشعارات دورية للمسؤول.

---

## المميزات الرئيسية

### 1. مرونة وتخصيص كامل لأي عزبة
- تسمية العزبة وتحديد **عدد الغرف** و**عدد السكان** وتوليد الشخصيات تلقائياً أو تعديل كل ساكن بشكل فردي.
- تخصيص **دورة الإيجار** (شهري، كل شهرين، كل 3 أشهر مثل الافتراضي `4,500` كل 3 أشهر، 6 أشهر، أو سنوي) مع خيار تقسيم الدورة على أقساط شهرية.
- خيار مرن لـ **فاتورة الماء**: اختيار ما إذا كان الماء **مشمولاً ضمن الإيجار** أو **مستقلاً** ليُقسم شهرياً بالتساوي مثل الكهرباء.
- اختيار العملة المناسبة (`ر.س`، `ر.ي`، `ج.م`، `د.إ`، `د.أ`، `د.ك`، `$`).

### 2. لوحة تحكم تنفيذية وفصل واضح للمستحقات
- عرض **المتبقي للتحصيل**، **المحصّل**، **الإجمالي**، **المتبقي السابق**، و**الأرصدة المدفوعة مقدماً** في بطاقة رئيسية واضحة.
- فصل كامل لكل ساكن بين:
  - **نصيب السكن**
  - **نصيب الكهرباء**
  - **نصيب الماء** (عند تفعيل الماء المنفصل)
- تصفية فورية حسب الغرفة أو حالة الدفع (`لم يدفع` / `جزئي` / `خالص` / `مدفوع مقدماً`) مع شريط بحث بالاسم.

### 3. دعم الدفعات المتقلبة والأرصدة المقدمة (Advance Credit)
- دعم واقعي لكل حالات السداد اليومية:
  - دفع **3 أشهر كاملة** مرة واحدة أو دفع **شهرين** مقدماً.
  - دفع مبلغ نقدي مرن (مثل **200 فقط** أو أي مبلغ يحضره الساكن) أو تقسيم مخصص.
- أي مبلغ زائد عن مستحق الشهر الحالي يُحفظ تلقائياً كـ **رصيد مدفوع مقدماً** (`ADVANCE_CREDIT`) ويُخصم تلقائياً من مستحقات الأشهر القادمة عند الترحيل.
- أي مبلغ غير مسدد يُرحّل تلقائياً كـ **متبقي مرحّل من السابق** عند الانتقال للشهر التالي.

### 4. رسائل واتساب طبيعية وودّية + إشعارات دورية
- صياغة طبيعية محترمة لرسائل التذكير الفردية (مثل: *"مساك الله بالخير أخي ... حبيت أذكرك بمستحقات ... كوننا بدأنا السداد"*), مع خيار رسالة مختصرة، أو رسالة طمأنة لمن لديه رصيد مقدم، بالإضافة لمشاركة ملخص العزبة للمجموعة.
- إشعارات دورية للمسؤول تنبّهه بمواعيد فاتورة الكهرباء والإيجار والمتبقي حتى اكتمال التحصيل.

### 5. تحليل الكهرباء وقراءة العداد
- تسجيل القراءة السابقة واللاحقة للعداد وحساب الاستهلاك بالكيلوواط ومتوسط التكلفة.
- مقارنة تلقائية مع الشهر السابق ورسم بياني تفاعلي لآخر 6 أشهر مع سجل الفواتير السابقة.

## التقنيات المستخدمة

- **اللغة:** Kotlin
- **واجهة المستخدم:** Jetpack Compose + Material Design 3 + خط `Cairo`
- **قاعدة البيانات المحلية:** Room Database + KSP + Coroutines & Flow
- **التنقل:** Jetpack Navigation Compose (مع دعم الهواتف والشاشات الواسعة `NavigationBar` / `NavigationRail`)
- **التنبيهات:** `AlarmManager` + `NotificationCompat` (`POST_NOTIFICATIONS` على Android 13+)
- **الاختبارات:** JUnit + Robolectric

---

## متطلبات البناء والتشغيل محلياً

- **JDK:** 21 (أو 17+)
- **Gradle:** 9.3.1
- **Android SDK:** Compile & Target SDK 36 (`minSdk` 24)

```bash
# تشغيل اختبارات الوحدة
gradle :app:testDebugUnitTest

# بناء نسخة Debug
gradle :app:assembleDebug
```
