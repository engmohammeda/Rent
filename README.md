# إدارة السكن (Sakan Manager)

تطبيق أندرويد احترافي باللغة العربية (واجهة RTL كاملة) لإدارة إيجار الشقق المشتركة وفواتير الكهرباء الشهرية، وتقسيم المستحقات على السكان بعدالة ووضوح، مع تتبع المدفوعات الجزئية وترحيل المتأخرات تلقائياً، وتحليل استهلاك الكهرباء، وإرسال تذكيرات عبر واتساب وإشعارات دورية للمالك.

---

## المميزات الرئيسية

### 1. لوحة تحكم مالية شاملة
- عرض **المتبقي للتحصيل**، **المحصّل**، و**الإجمالي المطلوب** مع نسبة السداد وشريط تقدم مباشر.
- فصل كامل وواضح لكل ساكن بين:
  - **نصيب السكن** (مع احتساب وعرض القسط الشهري تلقائياً عند اختيار دورة إيجار كل 3 أشهر، مثل 5,000 ÷ 3 ÷ عدد السكان).
  - **نصيب الكهرباء** للشهر الحالي.
  - **المتبقي المرحّل من الشهر السابق** بتنبيه بارز.
- تصفية سريعة حسب الغرفة أو حالة الدفع (مدفوع بالكامل / دفع جزئي / لم يدفع) مع البحث بالاسم.

### 2. مرونة تسجيل الدفعات (حسب ما أحضره الساكن)
- تسجيل **سداد كامل** أو **قسط شهري** أو **كهرباء فقط** أو **سكن فقط** بضغطة واحدة.
- إدخال أي **مبلغ مخصص** يدفعه الساكن وتوزيعه تلقائياً (الكهرباء أولاً أو السكن أولاً) أو تقسيمه يدوياً مع حفظ سجل زمني كامل للمدفوعات.
- وضع **تحديد الدافعين** لتحديد عدة سكان معاً واعتماد سدادهم الكامل دفعة واحدة.

### 3. التوليد التلقائي للسكان والتعديل المرن
- إدخال عدد الغرف وعدد السكان لتوليد شخصيات السكان وتوزيعهم على الغرف وحساب نصيب الفرد تلقائياً.
- إمكانية تعديل اسم أي ساكن، رقم الغرفة، رقم الواتساب، أو حالة النشاط في أي وقت.

### 4. الترحيل التلقائي للمبالغ المتبقية
- عند إغلاق الشهر الحالي أو الدخول في شهر جديد، تترحّل أي مبالغ غير مدفوعة تلقائياً إلى الشهر التالي وتظهر بوضوح كـ **متبقي مرحّل من الشهر السابق**.

### 5. تحليل الكهرباء وقراءة العداد
- تسجيل القراءة السابقة واللاحقة للعداد وحساب إجمالي الاستهلاك (ك.و.س) ومتوسط تكلفة الكيلوواط ونصيب الفرد.
- مقارنة مباشرة مع الشهر السابق (فرق التكلفة، نسبة الزيادة أو النقصان، وفرق الاستهلاك).
- رسم بياني تفاعلي يقارن فواتير آخر 6 أشهر مع إمكانية إضافة فواتير أشهر سابقة.

### 6. تذكيرات واتساب وإشعارات المالك
- إرسال رسالة واتساب مخصصة ومفصلة لكل ساكن تشمل نصيبه من السكن والكهرباء والمتبقي السابق.
- قائمة **التذكير الجماعي** ومشاركة ملخص الشقة كاملاً للمجموعة.
- جدولة إشعارات دورية للمالك تنبهه باقتراب موعد فاتورة الكهرباء والإيجار وتستمر بالتذكير حتى يتم سداد جميع المستحقات بالكامل.

## التقنيات المستخدمة

- **اللغة:** Kotlin
- **واجهة المستخدم:** Jetpack Compose + Material Design 3 + خط `Cairo`
- **قاعدة البيانات المحلية:** Room Database + KSP + Coroutines & Flow
- **التنقل:** Jetpack Navigation Compose (مع دعم الهواتف والشاشات الواسعة `NavigationBar` / `NavigationRail`)
- **التنبيهات:** `AlarmManager` + `NotificationCompat` (`POST_NOTIFICATIONS` على Android 13+)
- **الاختبارات:** JUnit + Robolectric

## البناء التلقائي وإصدارات GitHub (CI/CD & Releases)

يحتوي المستودع على ملف `.github/workflows/release.yml` لبناء التطبيق تلقائياً ونشره في صفحة **Releases** على GitHub:

- يعمل تلقائياً عند الدفع إلى فرع `main` / `master` أو عند إنشاء Tag يبدأ بـ `v` (مثل `v1.0.0`)، أو يدوياً عبر **Actions → Build & Publish Android Release → Run workflow**.
- ينتج عن كل تشغيل:
  - `SakanManager-release.apk` (للتثبيت المباشر على أندرويد)
  - `SakanManager-release.aab` (للنشر على Google Play)

### إعداد مفاتيح التوقيع الرسمية (اختياري وموصى به للإنتاج)

لضمان توقيع كل الإصدارات بنفس المفتاح الرسمي بدلاً من المفتاح المؤقت:

1. أنشئ ملف Keystore جديد (باسم alias `upload`):
   ```bash
   keytool -genkeypair -v -keystore my-upload-key.jks -alias upload \
     -keyalg RSA -keysize 2048 -validity 10000
   ```
2. حوّل الملف إلى نص Base64:
   ```bash
   base64 -w 0 my-upload-key.jks
   ```
3. أضف القيم التالية في المستودع عبر **Settings → Secrets and variables → Actions → New repository secret**:
   - `KEYSTORE_BASE64`: النص الناتج عن أمر `base64`
   - `STORE_PASSWORD`: كلمة مرور الـ Keystore
   - `KEY_PASSWORD`: كلمة مرور المفتاح (`upload`)

> إذا لم تُضف هذه الأسرار بعد، سيقوم الإجراء تلقائياً بإنشاء مفتاح توقيع داخل بيئة GitHub Actions حتى يكتمل بناء الإصدار وظهوره في **Releases** فوراً.

## التثبيت من الإصدارات

1. انتقل إلى تبويب **Releases** في صفحة المستودع على GitHub.
2. حمّل ملف `SakanManager-release.apk` من أحدث إصدار.
3. ثبّت الملف على هاتفك الأندرويد (مع السماح بالتثبيت من مصادر غير معروفة عند الطلب).
